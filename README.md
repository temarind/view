# Просмотр

Страница показывает содержимое закрытого репозитория тому, у кого есть ключ доступа к нему.
Данных на странице нет: она получает их с ключом пользователя прямо из GitHub и хранит только в его браузере.

Используются библиотека markdown-it (лицензия MIT) и шрифт Inter (SIL Open Font License 1.1, текст — в fonts/LICENSE.txt).
